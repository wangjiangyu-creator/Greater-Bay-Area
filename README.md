# 粤港澳大湾区法制一体化研究门户

本项目是“规则衔接、机制对接”研究门户和资料库的第一期静态网站。

## 本地运行

```bash
npm install
npm run content:seed
npm run dev
```

默认开发地址是 `http://127.0.0.1:4321/`。如果 4321 已被占用，Astro 会自动使用下一个可用端口；本次本地验收使用的是 `http://127.0.0.1:4323/`。

## 检查

```bash
npm run check
```

该命令会依次检查内容元数据、单元测试和静态构建。

## 内容目录

- `src/content/topics`: 专题研究
- `src/content/sources`: 政策与法源
- `src/content/cases`: 典型案例
- `src/content/comparisons`: 三法域规则对照
- `src/content/outputs`: 研究成果

## 页面结构

- 首页：研究总览、专题统计、第一期专题、近期资料、案例与成果。
- 专题：每个专题沉淀研究问题、机制类型、关联法源、案例和成果。
- 法源：政策、规划、案例批次和后续法律资料的结构化入口。
- 案例：围绕实施路径、创新点、效果和学术分析角度形成研究卡片。
- 对照：以专题为单位呈现内地、香港、澳门规则差异与对接空间。
- 成果：总报告、论文题单、工作论文和政策简报等产出记录。
- 检索：按标题、摘要、状态、可见性和标签检索全站内容。

## 内容维护

新增资料时优先放入对应的 `src/content/*` 目录，并保持 frontmatter 字段完整。所有条目都应填写 `status` 和 `visibility`，并通过 `topics`、`relatedSources`、`relatedCases` 等字段建立反向关联。

提交前运行：

```bash
npm run content:verify
npm run check
```
