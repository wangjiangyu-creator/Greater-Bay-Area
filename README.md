# 粤港澳大湾区法制一体化研究门户

本项目是“规则衔接、机制对接”研究门户和资料库的第一期静态网站。

## 本地运行

```bash
npm install
npm run content:seed
npm run dev
```

## 检查

```bash
npm run check
```

## 内容目录

- `src/content/topics`: 专题研究
- `src/content/sources`: 政策与法源
- `src/content/cases`: 典型案例
- `src/content/comparisons`: 三法域规则对照
- `src/content/outputs`: 研究成果
